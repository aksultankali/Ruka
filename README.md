# Ruka

Цифровая визитка: контакты, QR-код и NFC.

- `index.html` — готовый сайт. Его можно выложить на любой статический хостинг.
- `contact.vcf` — контакт для телефонной книги.
- `build.py` — меняете данные в `CONTACT` и запускаете `pip install segno && python3 build.py`.
- `templates/card.html` — дизайн страницы.

QR-код содержит сам контакт (vCard): если навести на него камеру, телефон предложит сохранить контакт.
NFC-метка должна хранить ссылку на опубликованную страницу. Записать её можно бесплатным приложением NFC Tools
или кнопкой «Записать ссылку на NFC-метку» на самой странице (Chrome на Android).
